# 점심 메뉴 추천

## 🚀 기능 구현 목록

### 1. 입출력 (View)
- [X] **입력**
  - [X] 메뉴 추천을 받을 코치의 이름을 입력 (구분자 ",", 최소 2글자 최대 4글자, 최소 2명 최대 5명)
  - [X] 각 코치가 못 먹는 메뉴 입력 (0개에서 최대 2개, 구분자 ",")
- [ ] **출력**
  - [ ] 서비스 종료 문구
  - [ ] 에러 메시지 출력 (`[ERROR]` 접두사 포함)

### 2. 비즈니스 로직 (Domain)
- [ ] **핵심 객체 Coach**
  - [ ] name, menu
  - [ ] 핵심 동작 구현 (예: 전진 조건 판단)
- [ ] **보조 객체 Menu**
  - [ ] 컬렉션 관리 및 비즈니스 규칙 적용
- [ ] **보조 객체 Category**
- [ ] **관리 객체 RecommendService**
  - [ ] 카테고리 무작위 선정 - (한 주에 같은 카테고리는 최대 2회만)
  - [ ] 카테고리 내 코치에 대한 메뉴 선정 (각 코치는 중복 메뉴를 먹으면 안 됨)

### 3. 예외 처리 (Exception)
> 모든 예외는 `IllegalArgumentException`을 발생시키며, `[ERROR]`로 시작하는 메시지를 출력한다.

- [ ] **입력 유효성 검증**
  - [X] [예외] 코치 이름 2~4글자 (validator)
  - [X] [예외] 코치 최소 2명 최대 5명 (validator)
  - [X] [예외] 정해진 구분자(쉼표 등) 형식이 아닌 경우 (Parser)
- [ ] **비즈니스 규칙 검증**
  - [ ] [예외] 숫자 범위(예: 1~45)를 벗어난 경우
  - [ ] [예외] 입력 길이/개수가 맞지 않는 경우
  - [ ] [예외] 중복된 값이 있는 경우
